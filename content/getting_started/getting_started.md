Start with the interface you need. Use the CLI when you want to process PDFs from
the terminal, scripts, or automation. Use the Go API when pdfcpu should become
part of your own application.

<div class="start-actions">
  <a href="/getting_started/install_cli/?src=docs">Install the CLI</a>
  <a href="/getting_started/install_api/?src=docs">Use the Go API</a>
</div>

## CLI

Download the `pdfcpu` binary and run PDF operations directly from your shell.

## API

Add pdfcpu as a Go dependency and call PDF processing functions from your code.

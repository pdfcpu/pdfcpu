# Forms

Form commands help you manage interactive PDF forms.

Use them with existing forms regardless of where the PDF came from:

* List form fields
* Remove fields by id
* Lock fields by id
* Unlock fields by id
* Reset fields by id
* Export form to JSON
* Fill form via JSON
* Multifill forms via JSON/CSV

You can also craft your own forms with [pdfcpu create](/create/create) using JSON, but the form commands are not limited to PDFs created by pdfcpu.

# Command Set

* [Booklet](/generate/booklet) (arrange pages onto larger sheets to make a booklet or zine)
* [Collect](/core/collect) a custom PDF page sequence
* [Create](/create/create) PDF file via JSON with optional form
* [Crop](/core/crop) (apply a custom crop box for selected pages)
* [Cut](/generate/cut) page (apply custom horizontal/vertical cuts)
* [Decrypt](/encrypt/decryptPDF) (remove password protection)
* [Encrypt](/encrypt/encryptPDF) (set password protection)
* [Extract Content](/extract/extract_content) (extract the PDF-Source into dir)
* [Extract Fonts](/extract/extract_fonts) (extract all embedded fonts of a PDF file into dir)
* [Extract Images](/extract/extract_images) (extract embedded images of a PDF into dir)
* [Extract Metadata](/extract/extract_metadata) (extract XML metadata)
* [Extract Pages](/extract/extract_pages) (extract specific pages into dir)
* [Grid](/generate/grid) (rearrange pages into grid layout for enhanced browsing)
* [Import](/generate/import) convert/import images into PDF
* [Info](/info) (print file info)
* [Merge](/core/merge) a set of PDF files into one consolidated PDF file
* [N-down](/generate/ndown) (cut page into n pieces - the "inverse" of N-up)
* [N-up](/generate/nup) (rearrange pages into grid layout for reduced number of pages)
* [Optimize](/core/optimize) (get rid of redundancies like duplicate fonts, images)
* [Paper](/paper) (print list of supported papersizes)
* [Poster](/generate/poster) (create poster tiles for given paper size or dimensions)
* [Resize](/core/resize) selected pages
* [Rotate](/core/rotate) selected pages
* [Signatures](/core/sign) (removes and validates digital signatures)
* [Split](/core/split) multi-page PDF into several PDFs according to split span
* [Trim](/core/trim) (generate a custom version of a PDF including selected pages)
* [Validate](/core/validate) PDF files up to version 1.7 + basic validation version 2.0
* [Version](/getting_started/config_dir) print version 
* [Zoom](/core/zoom) in/out of selected pages by magnification factor or corresponding margin
